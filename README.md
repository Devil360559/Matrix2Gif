# Matrix2Gif
For g-helper users, a Program to restore your ROG Anime Matrix functionality, by simply stitching the Animations together and exporting to g-helper. 

Custom Animations are also possible in the app by adding gifs of your own, and it supports importing .matrix files from Armoury Crate 

# Which Should I Download
There are both zip files and portable builds. 

The zip file has the main executable and the dll's packaged together. 

The portable executable contain the same files within the single .exe file, but they are extracted to a temporary folder every time it's run. 
(I made the singular exe file for people who don't regularly use the Anime Matrix and also don't want to keep a folder seperately for this program)

# Usage
You just need to run the program and then drag and drop whatever .matrix animations and gifs you want. 

There are features that let you reorder the sequence, reverse the direction of the gifs, change the brightness, transparent background, etc. 

And More Features To Come.
